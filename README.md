<summary><b>RU</b></summary>

Учебный SPA-проект интернет-магазина на React.

### Функционал
* Загрузка каталога товаров с внешнего API (`fakestoreapi.noksha.dev`) с обработкой состояний загрузки и ошибок.
* Добавление, удаление и изменение количества товаров (`+` / `-`) как в корзине, так и напрямую из карточек каталога.
* Подсчет общего количества позиций и итоговой стоимости заказа.

### Стек
* React (`useState`, `useEffect`, `useContext`)
* React Router v6
* Vite
* CSS

### Локальный запуск
```bash
git clone <repo-url>
cd shopping-cart
npm install
npm run dev
```

<summary><b>EN</b></summary>

E-commerce SPA pet project built with React.

### Features
* Product catalog fetched from an external API (`fakestoreapi.noksha.dev`) with loading and error handling.
* Add, remove, and update item quantities (`+` / `-`) directly from the catalog cards or inside the cart.
* Automatic calculation of total items and total price.

### Tech Stack
* React (`useState`, `useEffect`, `useContext`)
* React Router v6
* Vite
* CSS

### Local Setup
```bash
git clone <repo-url>
cd shopping-cart
npm install
npm run dev
```
